# Saad Ali Shaikh — Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript. It has no build step or package dependencies.

## Preview

Open `index.html` in a modern browser. The stylesheet and script are loaded from the same folder.

## Publish

Upload `index.html`, `styles.css`, and `script.js` to the root of a static hosting project, or use a host that can publish this folder as-is. The portfolio links to the public GitHub and LinkedIn profiles and uses the email listed in the résumé.

## Customize

- Update project descriptions and modal notes in `script.js`.
- Edit page sections and profile links in `index.html`.
- Adjust theme colors, layout, and responsive styles in `styles.css`.
